# 3 Вирусных сценария для Shorts / TikTok / Reels

Эти сценарии рассчитаны на 20-30 секунд. Они построены по формуле виральности: **Хук (боль) -> Демонстрация решения -> Призыв к действию**.

---

## Сценарий 1: «Как открыть порты без пароля от роутера»

**Длительность:** 20 секунд  
**Аудиоряд:** Динамичный трендовый бит / Lo-Fi фон  
**Хук (первые 3 секунды):** *«Пытаешься запустить сервер для друзей, но не знаешь пароль от роутера?»*

| Тайминг | Видеоряд на экране | Закадровый голос / Текст на видео |
| :--- | :--- | :--- |
| **00:00 - 00:04** | Открыта вкладка браузера `192.168.1.1` с ошибкой неверного пароля админки роутера | «Забудь про пароли от роутера и админку 192.168.1.1...» |
| **00:04 - 00:10** | Запуск `NetHub.exe` на рабочем столе. Мгновенно появляется статус сети и адрес `localhost:8080` | «Скачиваем бесплатную софтину NetHub с Гитхаба...» |
| **00:10 - 00:16** | Клик по кнопке «Открыть порт 25565 (Minecraft)». Статус меняется на зелёный «Успешно открыт через UPnP» | «Жмём одну кнопку — и программа сама открывает порт в роутере через протокол UPnP за 1 секунду!» |
| **00:16 - 00:20** | Ссылка на GitHub в описании профиля | «Качай бесплатно на GitHub по ссылке в профиле или комментариях!» |

**Хэштеги:** `#minecraft #сервермайнкрафт #пк #лайфхак #роутер #программирование #игры`

## Сценарий 2: «Почему друзья не могут зайти на твой сервер (Серый IP)»

**Длительность:** 25 секунд  
**Хук:** *«Друзья не могут подключиться к твоему серверу по IP? Тебя обманывает провайдер!»*

| Тайминг | Видеоряд на экране | Закадровый голос / Текст на видео |
| :--- | :--- | :--- |
| **00:00 - 00:05** | Скриншот из игры с бесконечным «Connecting to server... Timeout» | «Скинул друзьям свой IP из 2ip, а у них вечный тайм-аут?» |
| **00:05 - 00:12** | Запуск NetHub в консоли, стрелка указывает на надпись `GRAY_CGNAT` красным цветом | «Потому что провайдер выдал тебе СЕРЫЙ IP! Это значит, что твой комп спрятан за общим шлюзом с другими квартирами.» |
| **00:12 - 00:18** | Веб-панель NetHub с разделом рекомендаций (белый IP / Playit.gg) | «Утилита NetHub за секунду покажет правду о твоем IP и подскажет, как бесплатно обойти блокировку.» |
| **00:18 - 00:25** | Финальный кадр с GitHub репозиторием | «Прога бесплатная и опенсорсная, ссылка в шапке профиля!» |

**Хэштеги:** `#гейминг #сервер #palworld #кс2 #компьютер #софт #windows11`

## Сценарий 3: «Убей Hamachi раз и навсегда»

**Длительность:** 20 секунд  
**Хук:** *«Удали Hamachi прямо сейчас и перестань ловить лаги в играх!»*

| Тайминг | Видеоряд на экране | Закадровый голос / Текст на видео |
| :--- | :--- | :--- |
| **00:00 - 00:04** | Корзина Windows, в которую перетаскивается ярлык Hamachi | «Хватит мучаться с Хамачи, лимитом на 5 человек и пингом 300...» |
| **00:04 - 00:12** | Интерфейс NetHub, проброс портов и запуск сервера прямо из браузера | «С NetHub ты открываешь порты на своем роутере напрямую и играешь с друзьями на максимальной скорости твоего интернета.» |
| **00:12 - 00:20** | Демонстрация веб-панели управления сервером | «Работает на Windows 11, весит пару мегабайт, качай на Гитхабе!» |

**Хэштеги:** `#hamachi #radmin #игрысподругой #кооператив #пкигры #топсофт`
